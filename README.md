# SS25 / Manager OS

## Telegram Mini App

В проекте реализованы три режима одного Mini App, открываемого из двух Telegram-ботов:

- обучение менеджера: ответ на задание отправляется в очередь проверки;
- клиентский заказ: карточка, расчет, создание заказа и список трекинга;
- админская проверка: принять или отправить задание на доработку.

Доступ к обучению и заказам определяется валидированным Telegram WebApp initData; ID из SS25_ADMIN_IDS получает режим администратора. Следующий день обучения открывается только после статуса accepted.

Для проверки на телефоне Mini App должен быть опубликован по HTTPS. Локальный сервер слушает http://127.0.0.1:8080; подключите туннель на этот порт и задайте публичный URL в SS25_MINI_APP_URL, затем перезапустите local_run.py.

## Запуск

1. Заполните `.env` без публикации токенов.
2. Выполните `.runtime/python/python.exe local_run.py`.
3. Откройте в браузере `http://127.0.0.1:8080` для локальной панели.
4. В Telegram используйте кнопки Mini App после настройки HTTPS URL через BotFather.

Проверка backend: `.runtime/python/python.exe tests/test_server.py`.
